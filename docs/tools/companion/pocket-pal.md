# Pocket Pal

Pocket Pal is an interactive viewport companion with behavior settings, activities, customization, and persistent progression.

## Get started

Enable Pocket Pal, then open its preferences to choose the companion and behavior settings. Interact with it in the 3D Viewport. Progress and customization are saved in Blender's user data folder, so they persist between sessions.

Pocket Pal can run as a standalone add-on or through the Precision Toolkit Host. Do not enable both copies at the same time. It supports Blender 4.3 through 5.2.
