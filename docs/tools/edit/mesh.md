# Mesh

Mesh adds **Dimension Match** for measuring and matching selected mesh dimensions in Mesh Edit Mode.

## Workflow

1. Select the mesh topology whose dimension you want to use.
2. Run Dimension Match from the Mesh panel or F3.
3. Enter the target dimension in the operation controls and review the live dimension overlay.
4. Confirm the operation or adjust it in Blender's last-operation panel.

The live overlay and refresh service run only while the tool interface is active. Mesh supports Blender 4.3 through 5.2 and can run standalone or through the Host.
